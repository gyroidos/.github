# GyroidOS

GyroidOS (/dʒaɪrɔɪd/) is a multi-arch OS-level virtualization solution with additional focus on platform security based on hardware features.

Here, all of our source code related to the GyroidOS platform, especially the CML (Container Management layer) with our own
tools and daemons as well the Yocto Layers for our base distribution and reference core container image can be found.
If you want a general introduction to the project, see [gyroidos.io](https://gyroidos.io)
